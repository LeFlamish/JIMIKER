# 앱 아이콘 원본

`app_icon.png` 하나가 원본이다. 여기서 안드로이드 해상도별 아이콘을 만든다.

## 조건

- **1024×1024 PNG**, 정사각형
- 배경이 투명하지 않아야 한다 (플레이스토어는 투명 배경 아이콘을 받지 않는다)
- 캐릭터가 가장자리에 닿지 않게 여백을 조금 둔다

## 다시 만들기

```bash
dart run flutter_launcher_icons
```

`android/app/src/main/res/mipmap-*/` 와 `mipmap-anydpi-v26/` 가 덮어써진다.
그림을 바꿨으면 `app_icon.png`만 갈아끼우고 이 명령을 다시 돌리면 된다.

## 플레이스토어용 512×512

Console에는 아이콘을 따로 올려야 한다. `app_icon.png`를 512×512로 줄여서
쓰면 된다. (앱에 들어가는 아이콘과 같은 그림이어야 한다)
